# RTX Spark Atlas

[English](README.md) · [Türkçe](README.tr.md)

A detailed, representative **NVIDIA RTX Spark N1X / 128 GB** architecture explorer built with **Blender, Three.js, React and TypeScript**. The selected configuration has 20 Arm CPU cores and 6,144 CUDA cores. English and Turkish are available throughout the application.

**Status:** release workflow prepared for https://rtx.aserdargun.com/. Deployment identity and asset hashes are exposed in `/release.json`; live acceptance evidence is recorded separately.

## Explore

- 46 selectable parts, 20 individually selectable CPU cores and 6,144 logical CUDA count markers.
- Assembled, exploded and top views; layer separation, orbit, zoom, focus, labels, section isolation, auto rotation and PNG export.
- Data-flow, AI-inference and graphics scenarios with playback speed, pause and manual steps. Eight-chapter guided tour.
- Detailed architecture chapters, memory partition / bandwidth / model-weight calculators, and CUDA / Tensor / RT teaching examples.
- Fourteen primary NVIDIA references and downloadable native Blender and GLB files.
- Responsive desktop and mobile layout, keyboard-accessible component controls, self-hosted fonts, reduced-motion support and a poster fallback when WebGL cannot start.

The [design specification](docs/design/spec.md), [browser verification](docs/verification/browser-checks.en.md) and [model validation](docs/verification/model-validation.json) record the implementation and its limits.

## Run locally

Use Node.js 22.23 or newer in the Node 22 line; the tests use built-in TypeScript stripping. The lockfile pins dependencies.

```sh
npm ci
npm run dev
```

Development: `http://127.0.0.1:4317/`. For the production bundle:

```sh
npm test
npm run build
npm run preview
```

Production preview: `http://127.0.0.1:4318/`. Both servers bind to loopback and use strict ports. `dist/` contains deployable static files. Browser QA was performed through the Codex in-app browser; there is no claimed automated end-to-end suite.

## Rebuild the model

The model is original, reproducible geometry generated by [blender/build_atlas.py](blender/build_atlas.py). Blender 5.1.1 was used. Set `RTX_BLENDER` to a Blender executable if it is not on PATH or at the macOS default location.

```sh
npm run model
npm run model:optimize
npm test
npm run build
```

Outputs:

- [Native Blender scene](public/models/rtx-spark-n1x-128gb.blend)
- [Browser GLB](public/models/rtx-spark-n1x-128gb.glb)
- [Part and provenance manifest](public/models/architecture.json)
- [Blender poster](public/models/architecture-poster.png)

The raw GLB stays in ignored `blender/build/`. glTF Transform deduplicates, welds and prunes geometry while preserving semantic part groups. Khronos glTF Validator checks the optimized output. Native Blender downloads are not loaded during ordinary browsing.

## Evidence and representation

The user changed the scope on 2026-10-16 to **“temsili ama çok ayrıntılı şekilde yapalım”**. The application therefore represents documented functions and logical counts. It does not claim a dimensioned package, physical die floorplan, manufacturing geometry, memory-package count or actual SM topology. The 96 × 64 CUDA marker grid, Tensor/RT teaching regions, layer heights, materials and traces are illustrative.

Documented 300 GB/s DRAM bandwidth and announced 600 GB/s NVLink-C2C bandwidth describe different links. The keynote does not specify directional accounting for C2C. Memory-region values and transfer times are scenarios, not device readings or benchmarks. FP4 peak is not FP32 or sustained application throughput.

The original physical-blueprint search is preserved in [English findings](docs/research/findings.en.md), the [deeper source audit](docs/research/deep-source-audit.en.md) and the [source register](docs/research/physical-source-register.json). No qualifying dimensioned source was found in that bounded public search. This does not imply that such a source does not exist.
